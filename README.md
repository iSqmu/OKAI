


# OKAI

Este es el proyecto de cam y comercio que trata de una aplicación con visión artificial enfocada a lenguaje de señas.

## Dependencias

Se recomienda instalar Python v3.12 para evitar problemas con las instalaciones de las dependencias.
Para instalar las dependencias usar el siguiente comando:

```bash
    pip install flask opencv-python mediapipe pyautogui
```
