# OKAI 🤟

Proyecto desarrollado para facilitar la comunicación entre personas mediante el reconocimiento básico del **lenguaje de señas colombiano**.

OKAI utiliza técnicas de visión artificial para reconocer señas estáticas y convertirlas en texto, además de permitir convertir texto a voz.

El proyecto fue desarrollado para una competencia de la **Cámara de Comercio** y posteriormente presentado ante empresarios, universidades y diferentes entidades participantes.

## ✨ Características

- 🤟 **Reconocimiento de lenguaje de señas:** reconocimiento de señas estáticas correspondientes al abecedario.
- 📝 **Conversión a texto:** las señas reconocidas son transformadas en texto.
- 🔊 **Conversión de texto a voz:** permite convertir texto en audio.
- 📚 **Aprendizaje:** incluye un apartado destinado al aprendizaje del abecedario del lenguaje de señas colombiano.
- 🖥️ **Interfaz web:** aplicación desarrollada utilizando Flask, HTML, CSS y JavaScript.

## 🧠 Visión artificial

El reconocimiento de las señas se desarrolló utilizando herramientas de visión artificial y procesamiento de imágenes.

El proyecto utiliza:

- **OpenCV**
- **MediaPipe**
- **Python**
- **Pickle**

MediaPipe se utilizó para trabajar con la información obtenida de las manos, mientras que OpenCV permitió trabajar con el procesamiento de imágenes y video.
